# Smart Timetable Generator

## Overview

This project implements a Smart Timetable Generator using Backtracking in Java. It assigns subjects to time slots while avoiding conflicts such as teacher overlap and room clashes.

## Features

* Assign subjects to time slots
* Avoid teacher conflicts
* Avoid room clashes
* Generate a valid timetable

## Concepts Used

* Backtracking
* Constraint Satisfaction Problem
* Recursion

## Project Structure

src/
├── Main.java
├── Subject.java
└── Timetable.java

## How to Run

```bash
javac src/*.java
java -cp src Main
```
